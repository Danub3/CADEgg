# 电梯井口防护 Demo 工作流

## 目标

把「用户一句话」推进成「AutoCAD 生成标准防护布置图 + 确定性校核 + 可追溯结果」的最小闭环。

## 规范依据

《房屋市政工程安全生产标准化指导图册》（建办质函〔2019〕90号）**第 2.7.4 条「室内电梯井口防护」**：
电梯井口采用**定型化防护门**，分上翻式、三件套式两种（本 demo 采用上翻式）。

关键规格（图册 P126/P127）：
- 防护门高 **1.5m**，宽 **1.5m / 2.1m** 两种规格（按井口尺寸选定）
- 上口两端 Φ16 钢筋作翻转轴
- 底部 **200mm** 高踢脚板
- 外侧张挂「当心坠落 严禁抛物」警示牌

## 闭环流程

```text
用户输入施工条件
  -> 缺参追问（井口宽、井口高；防护门高/踢脚板为规范定值，无需追问）
  -> 检索标准图册知识卡（data/atlas/elevator_shaft_protection.json）
  -> 生成结构化绘图计划
  -> 调用 draw_elevator_shaft_protection 出图（上翻式防护门）
  -> 调用 validate_elevator_shaft_protection 校核
  -> 输出图纸 + 校核 JSON + 修改履历
```

## 演示固定指令（可直接粘贴）

```text
画一个电梯井口防护，井口宽 2000，高 1800，包含警示牌和材料表。
```

预期：

1. Agent 调用 `draw_elevator_shaft_protection`（防护门高/踢脚板自动按规范 1500/200）
2. Agent 调用 `validate_elevator_shaft_protection`
3. AutoCAD 生成上翻式防护门布置图
4. 前端对象表同步
5. 工具结果出现 JSON 校核，前端校核面板展示通过/未通过

## 缺参追问（用户只说「画一个电梯井口防护」时）

Agent 应优先追问，不自行编造关键尺寸：

- 井口宽度（现场实测）
- 井口高度/进深（现场实测）
- 是否包含警示牌
- 是否输出材料表

防护门高度（1.5m）、踢脚板高度（200mm）是规范定值，**无需追问**，缺省即用规范值。

## 工作模式

- `safety_demo_mode`：只暴露电梯井口防护闭环工具，屏蔽 `run_lisp` 与 Claude 入口。
- `competition_mode`：隐藏并阻断 `run_lisp`，隐藏 Claude。

## 验收要点

- 井口轮廓清楚
- 防护门（上翻式、两扇对开）覆盖井口，门高 1.5m
- 底部 200mm 踢脚板
- 上口两端翻转轴标记
- 警示牌「当心坠落 严禁抛物」、材料表、文字标注存在且不遮挡图形
- `zoom_extents` 后图面完整可见
- 返回 handle 可被前端会话状态稳定记录
