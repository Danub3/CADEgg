# CADEgg UI 重设计 — 像素风玻璃化

> 交付日期：2026-08-16
> 设计稿（Ardot 云端）：https://ardot.tencent.com/file/715314807041825
> 说明：本文档归档 CADEgg 前端 UI 重设计的完整视觉方案，供前端实现参考。

---

## 一、背景

原 UI 为 340px 悬浮窗（右侧滑入/滑出 + 玻璃拟态），用户反馈"鸡肋、不美观、无体验提升"，要求改为 WorkBuddy / Claude / Codex 式全屏 App 界面，视觉方向为**像素风 + 撞色 + 拼接**。在此基础上，进一步要求色块**半透明玻璃化**，支持设置中调整透明度/模糊度，窗口置顶时底层内容可透出。

### 像素风语言

- 所有面板 `corner-radius: 0`（零圆角）。
- 3px 墨色描边（`stroke: #1E1633`, `stroke-weight: 3`, `stroke-align: inside`）。
- 装饰条：顶栏下方 4px 明黄 + 2px 热粉双色条纹。

## 四、玻璃化参数

> 前端落地对应 `backdrop-filter: blur()` + 半透明 `background`。

| 面板类型 | 填充透明度 | 模糊 `backdrop-filter` | 阴影 |
|----------|-----------|----------------------|------|
| 侧栏 / 右面板 | 0.35 | blur(14px) | 柔化 8px |
| 顶栏 / LOGO 芯片 / 发送按钮（深色玻璃） | 0.65–0.75 | blur(16px) | — |
| 功能卡片 / 消息气泡 / 场景卡 | 0.40 | blur(14px) | 柔化 12px |
| 输入栏 | 0.40 | blur(14px) | — |
| 主框架 | 0 | — | — |
| 聊天区 | 0.12 | — | — |

玻璃三要素（Ardot 实现）：
1. `BACKGROUND_BLUR`（背景模糊，`blurType: NORMAL`）。
2. 半透明 `SOLID` 填充（opacity ≤ 0.5）。
3. 白色 `INNER_SHADOW` 高光边（`offset y:1, radius:2, opacity 0.15`）+ 柔化 `DROP_SHADOW`（`showShadowBehindNode: false`，避免阴影穿过透明区）。

### 可调参数（玻璃设置弹窗）

- **透明度**：默认 45%
- **模糊度**：默认 70%
- **边框样式**：`像素墨线`（选中）/ `柔和发光`

## 五、布局结构

### 会话主界面（1440×900）

```
顶栏（56px 深色玻璃）：LOGO + CADEgg | 会话标题 | BRIDGE 在线(绿LED)+端口 | 模式标签(黄框) | 模型标签(紫) | 设置齿轮
├─ 装饰条（黄4px + 粉2px）
└─ 主体
   ├─ 侧栏（240px 热粉玻璃）：新建会话 | 会话列表×3 | 导航(知识卡/工具箱/演示履历) | 设置+版本
   ├─ 主聊天区（米白）：消息流(用户/计划/工具/助手 + 思考指示器) + 输入栏(黄)
   └─ 右面板（296px 淡紫玻璃）：CAD连接 | 本次出图 | 安全校核 | 会话对象 | 演示履历
```

### 欢迎页（1440×900）

```
顶栏 + 装饰条（同上）
├─ 侧栏（简化）
├─ 主区：英雄区(LOGO芯片 + CADEgg + 副标题) + 场景卡×3 + 快捷提示×3 + 输入栏
└─ 右面板（仅 CAD 连接卡）
```
